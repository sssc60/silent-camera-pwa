# 手元カメラ / silent-camera-pwa

iPhone Safari向けの個人用カメラPWAです。HTML・CSS・JavaScriptだけで動作し、フレームワーク、CDN、広告、アクセス解析、ユーザー登録、外部APIを使用しません。

## データと音について

- JPEGと録画データはJavaScriptのメモリと一時的なBlob URLだけに保持します。サーバー、localStorage、IndexedDB、Cookieへ保存しません。撮り直しとページ終了でBlob URLを解放し、未保存データは失われます。
- Service WorkerのCacheStorageには固定のHTML・CSS・JS・アイコン・manifestだけを保存します。写真や動画はキャッシュしません。
- サイト独自のシャッター音・操作音を再生しません。OSやブラウザによる音や通知まで無効化するものではありません。動画プレビューも初期値でミュートです。録音を聞く場合は再生コントロールでミュートを解除してください。
- カメラ使用中を表示し、録画中は赤色表示と経過時間を示します。撮影後、停止操作、画面非表示、ページ離脱でカメラとマイクを停止し、復帰時に自動再開しません。
- 「共有して保存」はOSの共有シートへファイルを渡します。利用者がメールやクラウドを選べば共有先アプリが送信する場合があります。このサイト自身は撮影データを送信しません。
- 配信サーバーにはアプリファイル取得時の通常のHTTP通信が発生します。GitHub Pagesなどホスティング側のアクセスログまで無効化することはできません。

## ファイルと設定

| ファイル | 役割 |
| --- | --- |
| `index.html` | 日本語UI、iOSメタタグ、CSP |
| `styles.css` | ダークUI、縦横レイアウト、セーフエリア |
| `app.js` | カメラ、JPEG、録画、共有、データ解放・停止処理 |
| `manifest.json` | 相対パスの起動URL・スコープ、アイコン |
| `service-worker.js` | 固定アプリファイルのオフラインキャッシュ |
| `icons/` | SVG、192/512px PNG、maskable PNG、iOS用180px PNG |
| `tests/browser_smoke.py` | Chromiumの模擬カメラによる機能確認 |

設定方法と使用方法はコード内にもコメントしています。JPEG品質は`app.js`の`JPEG_QUALITY`、動画形式の優先順は`MIME_CANDIDATES`で変更できます。公開を更新する際は`service-worker.js`の`VERSION`も更新してください。新しいService Workerは既存タブが閉じるまで待機します。Safariの該当タブとホーム画面アプリを閉じ、再度開いて更新を確認してください。

## PCでの開発と確認

ビルド・依存パッケージのインストールは不要です。リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

PCのブラウザでlocalhostのポート8000を開きます。安全なコンテキストとして扱われるlocalhostは開発用途で利用できます。iPhoneからPCのLANアドレスへHTTPでアクセスしてもカメラは利用できません。実機ではGitHub PagesなどのHTTPS配信を使ってください。

構文確認:

```sh
node --check app.js
node --check service-worker.js
```

任意の自動機能確認にはPythonのPlaywrightとChromiumが必要です。アプリ本体にはこれらの依存はありません。クラウド環境にはすでに用意されています。

```sh
python3 tests/browser_smoke.py
```

別環境ではPython仮想環境内で`pip install playwright==1.62.0`、`python -m playwright install chromium`を実行できます。テストは`CHROMIUM_PATH`、システムのChromium、PlaywrightのChromiumの順で利用します。一時的なlocalhostサーバーと模擬カメラを起動し、終了時に停止します。`ffprobe`があれば保存動画の映像・音声トラックも検査します。模擬カメラの確認はiPhone実機確認の代わりにはなりません。

## GitHub Pagesへの公開

1. 全ファイル（`icons/`を含む）をGitHubの`main`ブランチへコミットしてpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** を **main**、フォルダを **/(root)** にして **Save** を押します。
5. 公開処理が完了したら表示されるHTTPSの公開URLを開きます。標準URLは `https://sssc60.github.io/silent-camera-pwa/` です。
6. **Enforce HTTPS** を有効にします。カスタムドメインも証明書の準備を待ち、HTTPSで開いてください。

参照URL、manifest、Service Workerのスコープとキャッシュ対象は相対パスなので、GitHub Pagesのプロジェクト用サブディレクトリにも対応します。公開リポジトリではソースも公開されますが、撮影ファイルをリポジトリへ保存する機能はありません。この実装作業では公開操作は実行していません。

## iPhoneでの使用・確認手順

1. 現行iOSのSafariでHTTPSの公開URLを開きます。初期画面は「カメラ停止中」で、カメラ権限をまだ要求しません。
2. Safariの共有メニューで **ホーム画面に追加** を選びます。通常タブとホーム画面からの起動を両方確認してください。
3. **カメラを起動** を押し、カメラを許可します。初期値は背面です。「カメラ使用中」とライブ映像を確認します。
4. **切り替え** で前面・背面を確認します。前面のライブ映像だけを鏡表示し、保存画像・動画は元の映像の向きです。
5. **写真** の白いボタンを押します。JPEGプレビューと解像度が表示され、カメラが停止することを確認します。解像度は`video.videoWidth`と`video.videoHeight`から取得します。
6. **共有して保存** を押します。`navigator.canShare({ files })`で対応を確認して共有シートへ渡します。「画像を保存」「ビデオを保存」「ファイルに保存」など利用できる項目を選びます。共有終了だけでは保存成功を判定できないため、保存先を確認してください。
7. **撮り直し** で前のデータを破棄し、カメラを再起動します。
8. **動画** を選び、音声**なし**で録画します。赤い録画表示と経過時間を確認して数秒後に停止します。再生・保存し、音声トラックがないことを確認します。
9. 撮り直し、音声を**あり**にしてマイクを許可します。「カメラ・マイク使用中」を確認し、停止後の動画でミュートを解除して録音を確認します。
10. 縦横に回転し、映像、プレビュー、ボタン、ノッチとホームインジケーターの余白を確認します。
11. 録画中に別タブ／別アプリへの移動と画面ロックを試し、カメラ・マイクの停止と自動再開しないことを確認します。取得できた録画はプレビューしますが、iOSの強制中断では失われる場合があります。
12. カメラ拒否と、音声あり録画でのマイク拒否を試し、日本語エラーを確認します。マイク拒否時に無断で無音録画へ切り替えません。音声なしを選ぶとカメラだけで録画できます。
13. 共有キャンセル時にもプレビューが残ることを確認します。ファイル共有非対応時はダウンロードへ進みます。共有のキャンセル以外のエラーでは、次のタップで「ダウンロードして保存」を実行します。
14. 初回オンライン読み込み後、オフラインでUIを開けることを確認します。カメラ権限やSafariの制限によりオフラインでの撮影可否は端末に依存します。

## 既知のiOS Safariの制限

- `getUserMedia`にはHTTPSと権限が必要です。アプリ内ブラウザでは制限される場合があるためSafariで直接開いてください。通常タブとホーム画面アプリでは権限の扱いが異なる場合があります。
- MediaRecorderの対応形式はiOSの版と端末に依存します。`isTypeSupported`でMP4（H.264/AAC）、MP4、WebM（VP9/Opus）、WebM（VP8/Opus）、WebMの順に調べます。対応形式がなければ写真のみ利用できます。対応の申告があっても負荷やコーデックにより録画が失敗する場合があります。
- 録画Blobの実際のMIME（なければRecorderのMIME）から`.mp4`か`.webm`を決定します。WebMの再生や写真アプリの「ビデオを保存」はiOSの版で異なります。非対応の場合は「ファイルに保存」を使ってください。
- Web Share APIにはタップなどの操作が必要で、形式やサイズでファイル共有可否が変わります。ダウンロードは通常「ファイル」側に保存され、写真アプリに直接保存できません。Safariがプレビューを開く場合は、その画面の共有・保存操作を使ってください。
- Webページは写真ライブラリへ無断で書き込めません。共有項目や実際の保存完了もページから制御・検証できません。
- `facingMode`は希望条件なので、カメラが1台の端末では切り替わらない場合があります。複数の背面レンズの個別選択には対応していません。
- 映像からのJPEGなので、標準カメラアプリと同じ解像度・HDR・HEIC・EXIF位置情報などは保証しません。写真のピクセルサイズと向きはその時点の映像に従います。
- 回転中の動画の解像度や向きはブラウザ依存です。安定した向きで保存するには録画開始前に向きを決めてください。
- 長時間・高解像度の録画はメモリ不足で失敗、ページ終了、データ消失を招く場合があります。短い録画ごとに保存してください。録画時間上限を設定・保証する機能はありません。
- バックグラウンド／画面ロック中の継続撮影は実装していません。非表示イベントで停止しますが、OSの即時凍結・終了では最終データを取り出せない場合があります。
- 自動インストール案内は表示しません。「ホーム画面に追加」を手動で使ってください。オフラインキャッシュはOSにより削除される場合があり、永久保存は保証しません。
- サイトの音を再生しない設計ですが、地域・端末・OSの挙動を回避したり無音を保証したりする機能ではありません。

## 検証範囲

JavaScript構文とChromiumの模擬カメラで機能を自動確認します。iPhone実カメラ、Safariの録画形式、iOS共有シート、写真アプリへの保存は、上の実機手順で別途確認してください。
